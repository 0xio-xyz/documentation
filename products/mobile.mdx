The **0xio Mobile App** brings the power of the Octra Network to your pocket. Built with React Native, it offers the same high-grade encryption as the extension but optimized for touch interfaces and mobile security.

## Mobile-Exclusive Features

### PIN & Biometric Security
Forget typing passwords every time. The mobile app integrates directly with your device's secure enclave.
* **PIN Code:** Set a 6-digit PIN with rate-limited retry protection.
* **FaceID / TouchID:** Log in and sign transactions using your unique biometric signature.
* **Secure Storage:** Your encrypted keys are protected by the device's hardware-backed Keychain/Keystore.

### Push Notifications
Stay informed with real-time alerts for incoming transactions, claim-ready private transfers, and network events.

### DApp Browser
Browse and interact with Octra dApps directly from the mobile wallet without leaving the app.

### NFT Support
Import and browse NFT collections, view owned tokens, and manage your NFT portfolio on the go.

### Address Book
Save and label frequently used addresses for quick access when sending transactions.

### Multi-Wallet Support
Create or import multiple wallets and switch between them seamlessly. All wallets use the same master root key derivation as the extension and desktop.

### Stealth Transfers
Send private FHE-encrypted transfers where the amount is hidden from everyone except the recipient.

### Bulk Send
Send to up to 5 recipients in a single batch, saving time on multi-party payments.

### RPC Proxy for Fast History
Transaction history is fetched through an RPC proxy that compresses responses from ~8MB to ~7KB, enabling fast loading even on slow connections.

### Dual-Network History
View a merged transaction history from both mainnet and devnet in a single timeline, with clear network indicators for each entry.

### Infinite Scroll Pagination
Transaction history loads progressively as you scroll, with no manual "load more" buttons.

### Sentry Crash Reporting
Automated crash reporting with session replay for stability improvements and rapid bug resolution.

### Dynamic Recommended Fees
The app recommends different OU fee amounts per operation type (standard transfer, FHE encrypt, decrypt, etc.) based on current network conditions.

### PVAC Key Switch Detection
Automatically detects when your PVAC public key has changed on-chain and triggers auto-recovery to re-register, ensuring uninterrupted private operations.

### Stealth Claim Caching
Previously claimed stealth transfers are cached locally, so the claim scan only processes new transfers on subsequent runs.

## Core Functionality

### Dashboard & Balances
The **Home Screen** provides a dual-view of your assets:
* **Public Balance:** Instantly visible OCT and tokens.
* **Private Balance:** Your FHE-encrypted wealth. Tap the "Eye" icon to reveal (requires authentication).

### Sending Assets
The **Send Flow** is optimized for one-handed use:
* **Scan to Pay:** Use the camera to scan QR codes for instant address entry.
* **Privacy Toggle:** Switch between "Public" and "Private" transfer modes with a single tap.

### Privacy Suite (FHE)
Just like the extension, you have full control over your visibility:
1.  **Encrypt:** Move funds from Public -> Private.
2.  **Decrypt:** Move funds from Private -> Public.
3.  **Claim:** Scan the blockchain for incoming private transfers and add them to your balance.

## Getting Started

### Creating a Wallet
1.  Download the app from [alpha.0xio.xyz](https://alpha.0xio.xyz/).
2.  Tap **"Create New Wallet"**.
3.  **Backup your Recovery Phrase:** You will be shown a 12-word seed phrase. Write this down offline.
4.  **Enable Biometrics:** secure your vault with FaceID/Fingerprint.

### Importing
Already have the Browser Extension?
1.  Tap **"Import Wallet"**.
2.  Enter your **12-word seed phrase** from the extension.
3.  Your public and private balances will sync automatically.

## Smart Contract Interaction

The mobile app includes a **Tasks** screen for interacting with deployed smart contracts:

* **View calls**: Read contract state without a transaction (free).
* **Call**: Execute state-changing methods that cost gas (OU).
* **FHE parameter encryption**: Use `enc(42)` syntax to encrypt integer parameters before sending to the contract.
* **Auto-decrypt results**: Long return values are automatically tested for FHE decryption.

## FHE Tools

Standalone encrypt and decrypt tools are available for power users:

* **Encrypt**: Convert a plaintext integer to an FHE ciphertext.
* **Decrypt**: Recover the plaintext from an FHE ciphertext using your PVAC context.
