The **0xio Browser Extension** (v2.4.5) is your primary gateway to the Octra Network. Built with React 18 and Vite (Manifest V3), it lets you manage assets, interact with dApps, and perform private FHE operations directly from your browser.

<Note>
  **Status: Live on Chrome Web Store (v2.4.5) · Firefox build (v2.5.0) in review on Mozilla Add-ons** — Install from the [Chrome Web Store](https://chromewebstore.google.com/detail/0xio-wallet/anknhjilldkeelailocijnfibefmepcc).
</Note>

## Getting Started

### Installation & Setup
Once installed, you have three ways to set up your vault:

<CardGroup cols="3">
  <Card title="Create New" icon="plus">
    Generates a fresh 12-word seed phrase and a new Octra address (`oct...`).
  </Card>
  <Card title="Import Wallet" icon="file-import">
    Restore an existing wallet using a **Private Key** or **Seed Phrase**.
  </Card>
  <Card title="Watch Mode" icon="eye">
    Track any public address without needing a private key (View Only).
  </Card>
</CardGroup>

<Note>
  **Security Tip:** During setup, you can set a **Master Password**. This encrypts your keys on your device. If you skip this, your wallet relies solely on device-level security.
</Note>

## Dashboard Overview

The main screen gives you a snapshot of your financial privacy.

* **Public Balance:** Your visible `OCT` balance, usable for standard transactions and gas fees.
* **Private Balance:** Your FHE-encrypted balance. These funds are visible only to you and are used for shielded transfers.
* **Portfolio Worth:** Real-time USD value of your holdings powered by the 0xio Oracle (CoinGecko + DexScreener aggregation). Toggle between USD and OCT display.
* **24h Chart:** Portfolio worth chart reflecting actual price movement over the last 24 hours. Hover to see interpolated worth at any point in time.
* **24h Change:** Percentage change in portfolio value based on oracle price data.

## Sending Assets

Navigate to the **Send** tab to transfer funds. 0xio supports two distinct transfer modes:

### 1. Standard vs. Private (FHE)
You can toggle between modes using the slider at the top of the Send screen.

| Mode | Icon | Description |
| :--- | :--- | :--- |
| **Standard** | <Icon icon="unlock" /> | A transparent blockchain transaction. Sender, receiver, and amount are public. |
| **Private (FHE)** | <Icon icon="shield" /> | Uses Fully Homomorphic Encryption. The amount is encrypted locally before sending. Supports **stealth transfers** where the recipient's privacy is also preserved. |

### 2. Bulk Sending
Need to pay multiple people? Switch to **Bulk Mode**.
* **Capacity:** Add up to **5 recipients** in a single transaction batch.
* **Efficiency:** Signs all transactions in one go to save time.

### 3. Network Fees (OU)
For advanced users, you can customize the **Operational Unit (OU)** fee to prioritize transactions during network congestion.
* **Default:** 10,000 OU (Standard) / 30,000 OU (High Value).
* **Custom:** Click "Est. Network Fee" at the bottom to set a custom value.

## Privacy Operations

The **Privacy** tab is the control center for Octra's FHE capabilities. It handles moving funds between your public and private states.

<Steps>
  <Step title="Encrypt (Public → Private)">
    Moves `OCT` from your Public Balance to your Private Balance. A **review sheet** shows the transaction details (from/to, amount, fee, total) before confirmation. MAX button available to encrypt your full balance (minus fee reserve).
    * *Use case:* Prepare funds for a private transfer.
  </Step>
  <Step title="Decrypt (Private → Public)">
    Moves funds back to your Public Balance. Includes FHE encryption + range proof generation. A **proof overlay** shows real-time progress: verify → encrypt → range proof (with circuit counter) → submit.
    * *Use case:* Cashing out or sending to an exchange that doesn't support FHE.
  </Step>
  <Step title="Claim Transfers">
    If someone sends you a **Private Transfer**, it doesn't appear in your balance immediately. Navigate to the **Claim** tab to scan for pending transfers. The scan shows live progress ("Scanning 80/150 outputs (2 found)..."). Once found, review and claim individual transfers or all at once with a **claim review sheet** showing output details and fees.
  </Step>
</Steps>

## Asset Management

### Token Auto-Discovery

The extension automatically discovers tokens associated with your address and displays them on the dashboard. You can also manually import any fungible token.

### Custom Token Import

Import any fungible token by entering its contract address. The extension validates the contract on-chain (checking `name`, `symbol`, and `decimals`) and tracks your balance via `balance_of`. Imported tokens appear alongside the default token list and can be managed in **Settings > Imported Tokens**.

### NFT Gallery

The **NFTs** tab in the wallet dashboard lets you import and browse NFT collections.

<Steps>
  <Step title="Import Collection">
    Click the **+** button on the NFTs tab and enter a contract address. The extension validates it by calling `collection_name()`, `symbol()`, and `total_supply()` view functions. Supports SNS-1 (Spectrum) and Geodesics (Euint Labs) NFT standards.
  </Step>
  <Step title="View Owned NFTs">
    Each collection card shows how many NFTs you own (via `balance_of`). Click a collection to expand it and see individual token IDs.
  </Step>
  <Step title="Token Metadata">
    When expanded, the extension fetches `token_uri` for each owned token. Contracts without enumeration support still display the owned count.
  </Step>
</Steps>

<Note>
  NFT collections are stored per-network and auto-refresh every 60 seconds. To remove a collection, click the **⋮** (three-dot) menu on the collection header and select **Remove Collection**.
</Note>

## FHE Tools in Contract Calls

When interacting with smart contracts, the extension supports inline FHE encryption of parameters using the `enc(42)` syntax. Return values from contract calls are automatically tested for FHE decryption, allowing seamless encrypted contract interaction.

## dApp Interaction

When a dApp requests a transaction or message signature, the extension opens an approval popup with:

* **Origin verification:** The requesting site's domain and favicon are displayed prominently.
* **Wallet context:** Shows which wallet address will sign the transaction.
* **Network fee (OU):** Displays the estimated Operational Unit cost.
* **Auto-reject:** If the popup window is closed without a response, the request is automatically rejected — no timeout delay.

## RFC-O-1 Provider Standard

The extension implements the **RFC-O-1** wallet provider standard, exposing `window.octra` for third-party wallet and dApp interoperability.

```javascript
// Any RFC-O-1 compliant dApp can connect
const accounts = await window.octra.request({ method: 'octra_requestAccounts' });
const balance = await window.octra.request({ method: 'octra_getEncryptedBalance' });

// Listen for events
window.octra.on('accountsChanged', (accounts) => { ... });
window.octra.on('connect', (info) => { ... });
```

The `@0xio/sdk` includes an `OctraProviderAdapter` that automatically uses `window.octra` as a transport, so any RFC-O-1 compliant wallet works with the SDK.

## Desktop Companion Mode

When the **0xio Desktop** app is running on the same machine, the extension automatically connects to it and offloads heavy FHE computations to native code.

* **Automatic pairing:** No setup required — the extension detects the desktop app on `127.0.0.1`.
* **Faster privacy operations:** Range proof generation drops from ~80 seconds (WASM) to ~17 seconds (native Rust). Decrypt operations also benefit from parallel PRF computation.
* **Status indicator:** A "Desktop Connected" badge appears when paired.

<Tip>
Install the 0xio Desktop app to significantly speed up encrypt, decrypt, and claim operations. See the [Desktop Wallet](/products/desktop) page for details.
</Tip>
